# 🤖 AI/ML Developer Portfolio

**Modern. Interactive. Pure Code.**

A sleek, visually immersive portfolio built from scratch with HTML, CSS and JavaScript—no frameworks, no bloat.
Showcases technical skill through smooth animations, interactive UI, and a clean AI/ML-focused design.

---

## ✨ Features

- 🎬 **AI-Themed Loading Experience**
  - Neural network animation with floating tech symbols (🤖 🧠 ⚡ 📊)
  - Smart progress tracking — loading percentage with dynamic status messages
  - Smooth transitions from loading → welcome → portfolio

- 🌟 **Interactive UI Section**
  - Glassmorphism design — frosted glass cards with backdrop blur
  - Mouse-tracking glow — project cards light up under your cursor
  - 3D hover effects — cards tilt and lift on interaction
  - Animated particle background — floating orbs that move in patterns
    
- 🧩 **Projects Section**
  - Interactive Cards with 3D hover effects and mouse-tracking glow
  - Tech Tags with individual color-coded animations
  - Live Integration with direct links to deployed projects
  - Clean Presentation optimized for quick project scanning
  - Ready for Expansion with easy-to-add future projects

- 👾 **Tech Stack Animation**
  - Core Stack: Python • C • JavaScript • HTML5 • CSS3
  - Dev Tools: Git/GitHub • VS Code • Problem Solving
 
- 📱 **Fully Responsive**
  - Optimized for desktop, tablet, and mobile devices
  - Smooth scroll reveal animations

---

## 🛠 Tech Stack

- **HTML5** – Semantic markup, accessibility
- **CSS3** – 	Animations, Grid/Flexbox, CSS Variables
- **JavaScript** – DOM manipulation, event handling
